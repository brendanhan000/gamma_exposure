Schwab re-authentication

Schwab refresh tokens expire every 7 days and cannot be renewed programmatically — this is the weekly re-login, without a terminal.

Step 1 · Approve on Schwab

Opens Schwab in a new tab. Log in and tap Allow. You'll land on a “can’t open the page” error — that is expected and correct.

OPEN SCHWAB LOGIN ↗

Step 2 · Paste the address bar

On that error page, tap the address bar, Select All → Copy, and paste it below. It must contain code=.

Paste within ~30 seconds of approving — the authorization code expires almost immediately.
